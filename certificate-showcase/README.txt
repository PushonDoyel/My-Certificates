CERTIFICATE SHOWCASE

Files:
- index.html
- style.css
- script.js
- assets/ (the three certificate images)

HOW TO RUN:
1. Keep the folder structure unchanged.
2. Open index.html in a browser.
3. Click a certificate to view it larger.
4. Use Download in the preview to save the certificate.

TO PUBLISH:
- Upload the complete folder contents to a GitHub repository.
- Enable GitHub Pages in the repository settings, using the main branch and root folder.
- Your site will then be available at the GitHub Pages URL shown by GitHub.

You can change the page title, headings, and certificate details in index.html.
